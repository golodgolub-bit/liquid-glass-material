# v0.11 — Contours, interface recipes and portable HTML

- Add optical reach adaptation for narrow contours and union necks; preserve medial-axis derivative magnitude and stabilize distance scaling.
- Add text and alpha-mask shape factories, configurable 32–1024 contour resolution and coherent hit testing.
- Add runtime `surface.layer()` / `renderer.setLayer()` without replacing identities, springs or content. A union moves together.
- Add a clock/dock/launcher example using real glyph contours, composited icons, reversible panel transitions and layer changes.
- Build standalone HTML demonstrations from the current sources, with relative navigation and version metadata.
- Expand developer guides for theme architecture, native hosts, Apple calibration, thin-contour quality and deployment.

The default raised bevel remains zero. `edgeAdaptation: 0` allows the older optical reach when intentionally desired. Full custom shaders that decode shape-map BA channels must adopt the signed-derivative encoding described in [Edge quality](edge-quality.md).

The portable renderer does not replace a platform compositor or grant launcher permissions. Native parity, device performance and browser coverage are reported in [Validation](validation.md), [Performance](performance.md) and [Compatibility](apple-audit.md).
