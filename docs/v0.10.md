# v0.10 — Controls and motion foundations

Switches and sliders now compose their actual tracks behind a dense resting thumb. During interaction the cap fades, the thumb expands into a refractive lens and release restores a clear endpoint. The switch proportions and interaction profile were revised using public control demonstrations; exact native coefficients and timing are not claimed.

## Changes

- Redesign the switch with a wider track, pill-shaped thumb, captured drag/cancel, single-commit events, RTL, disabled state and on/off marks.
- Keep light thumb content opaque at rest and expose programmable resting/active material, content opacity, colors, spring profiles and press deformation.
- Render switch/slider track content inside the compositor, so it can actually refract through the active thumb. Keep DOM tracks transparent.
- Preserve the slider's native range input and keyboard semantics, with a denser resting thumb and programmatic visual press controls.
- Add `SurfaceOptions.contentOpacity`, `SurfaceHandle.contentOpacity` and state inspection. Local foreground can fade independently of the glass material.
- Reuse same-sized local-content texture allocations and expose `RenderStats.contentUploads` for upload diagnostics.
- Expand magnification to 0.5–2 for transmitted-image minification as well as enlargement.
- Add `/examples/controls/`, four foundation guides, updated real-render artwork and control-specific regressions.

Start with [Quick start](quick-start.md), [Basic controls](basic-controls.md), [Switches](switches.md) and [Animation basics](animation-basics.md). See [Validation](validation.md) and [Performance](performance.md) for measured coverage and limits.

Existing constructor calls remain valid. The control visuals and switch dimensions intentionally change; check application layouts that assumed the older narrow track. A full replacement shader implementing the local-content pass must support the new `contentOpacity` uniform to animate that content. Template hooks preserve it automatically.
