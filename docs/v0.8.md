# v0.8 — Composited readability and material response

Foreground selection now measures the completed material, including rear-layer content, using per-surface asynchronous GPU tiles. Regular can add bounded neutral protection; Clear selects ink without adding that protection. Contrast regions, target ratios, explicit ink policies, diagnostics and `contrastReady()` are public API.

Directional edge illumination has independent intensity and width and remains active at `bevel: 0`. Geometry-dependent thickness, refraction, frost, scattering and shadows are enabled by default and independently configurable. Scattering amount now changes smoothly across its full range; its width, shadow radius/offset and ambient color contribution are exposed separately.

## Migration

- Clear's default appearance changes from `dark` to `auto`. Set `appearance: 'dark'` for the previous light ink, or use a contrast ink policy. `materials.clearDimmed` supplies a 35% dimming preset for bright imagery.
- `state.material` contains effective size-adapted parameters. Read `state.baseMaterial` for the current unscaled material springs. Set `sizeAdaptation: false` for coefficient studies, custom artwork or an existing manually scaled component.
- Regular readability protection is enabled by default. Disable it per surface with `contrast: false`, or globally with `RendererOptions.readability: false`. Explicit ink remains available.
- Full custom fragment shaders can retain the `readability`, `edgeFinish` and `diffusion` uniforms to participate in the standard response. Template hooks preserve them automatically.

The new `/examples/readability/` study demonstrates rear-layer contrast, Clear presets, continuous size response and edge controls. Read [Composited contrast](readability.md), [Material response](material-response.md) and the generated [API](api.md) for integration details.

Validation covers 23 unit tests and 57 browser checks. At 800x500 / DPR 1 on Intel UHD / Edge D3D11, default GPU medians range from 0.53 ms for one surface to 7.12 ms for eight stacked surfaces; frame p95 values still exceed a 60 Hz budget. Both default and spectral benchmark runs sleep at rest. See [Performance](performance.md) for complete measurements.

Native Apple equivalence is not established by these changes. Optical equations and regression tests verify this implementation; matched native reference captures remain necessary for calibration.
