# Оптика, движение и захват v0.3

## Исправления

Причина повторяющихся полос за стеклом — растянутое разреженное ядро размытия. На тонкой линии оно давало несколько отдельных следов. Вместо него используются два плотных separable Gaussian-уровня: умеренное и широкое рассеивание, четыре прохода только при изменении фона. Предварительная mip-фильтрация исходника подавляет aliasing при уменьшении. Frost плавно выбирает рассеивание; сильный материал не возвращает резкую копию текста. Линза, источник и рассеивание используют общий viewport и UV.

Преломление теперь выводится из нормали выпуклого профиля, `refract` и показателя `ior`. Отдельно управляются увеличение и дисперсия. Fresnel меняет вклад отражения по углу: отражённый свет берётся из окружающего изображения. Направленные источники дают основной и встречный блики; касание добавляет широкую подсветку. Периодическая водяная волна удалена. В области слияния сохраняется уменьшение градиента: нормализация почти нулевой нормали не должна создавать внутренний шов. Профиль углов `cornerPower` меняет непрерывность; полноценные круги и капсулы сохраняют круговую геометрию.

`bindDrag` использует быструю критически затухающую пружину во время удержания и более мягкую при отпускании. Координаты учитывают отношение CSS viewport к canvas. Глобальная маршрутизация сохраняет перенос вне объекта; отказ `setPointerCapture` не прерывает захват. Есть совместимость с mouse-only вводом, обработка отмены и потери фокуса. Координаты отпускания также применяются, даже если хост не прислал последнего pointermove. Текст при переносе не выделяется.

```ts
const drag = bindDrag(glass, element, { surface: control.surface });
// При размонтировании: сначала drag.dispose(), затем control.dispose().
surface.motion({ frequency: 14, damping: 1 }); // меняет отклик без скачка позиции
surface.material({ ior: 1.48, reflection: 0.38, cornerPower: 2.6 });
```

`bindMediaBackdrop` захватывает изображение или декодированное видео с cover/contain/fill. Обрезка пересчитывается при resize; видео использует requestVideoFrameCallback. В лаборатории есть локальное открытие файла и дополнительные настройки света. Пример живого HTML тоже собирается в production и использует общий исправленный drag.

```ts
const media = bindMediaBackdrop(glass, imageOrVideo, {
  fit: 'cover', maxPixelRatio: 1.5,
});
// Управление воспроизведением остаётся у приложения.
media.dispose();
```

## Изученные материалы

- [Apple: Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/). Дополнительно просмотрены 20 кадров официального видео, включая появление линзы (176–183 с), свет под пальцем (230 с), switch/slider (249–266 с), меню (440 с), отражения и адаптацию (665–760 с). Видео читалось диапазонами без сохранения полного файла.
- [Apple: Animate with springs](https://developer.apple.com/videos/play/wwdc2023/10158/). Непрерывность скорости и различие между отслеживанием жеста и завершающим переходом.
- [Liquid Glass Studio](https://github.com/iyinchao/liquid-glass-studio): разделение SDF, нормалей, бликов, преломления и рассеивания; особое внимание к градиенту в области объединения.
- [Meniscus](https://github.com/thanhphuchuynh/meniscus): независимая модель профиля края и трассировки преломлённого луча.
- [OverShifted/LiquidGlass](https://github.com/OverShifted/LiquidGlass) и [KMPLiquidGlass](https://github.com/naohstudio/KMPLiquidGlass): дополнительные реализации и ограничения переноса на другие платформы.

Чужие проекты изучены как самостоятельные реконструкции, а не спецификация Apple. Эта реализация не использует приватные шейдеры Apple. Refraction — экранная модель выпуклой поверхности; reflection — выборка изображения окружения, не HDR/cubemap и не полная трассировка лучей. Цвет обрабатывается в sRGB. Формулы углов, профили и тайминги независимо подобраны. Попиксельное совпадение, все системные компоненты iOS и паритет FPS/энергопотребления не подтверждены.

## Проверки

Добавлены регрессии настоящего переноса мышью, отказа pointer capture, последней координаты отпускания, мелкой шахматной сетки, одиночной тонкой линии, обрезки изображения после resize и открытия локального изображения в UI. Проверка тонкой линии требует единственного плавного пика, чтобы прежние повторяющиеся полосы не вернулись. Проверки выполняются на настоящем WebGL 2 в Edge с ANGLE/D3D11. Нативные Android/Windows хосты по-прежнему требуют отдельной сборки SDK и испытаний на устройствах.

Итог: 12 unit-тестов и все 20 браузерных проверок прошли. ESM-пакет отдельно загрузился и отрисовал материал; declarations прошли независимую компиляцию с NodeNext. Обе сборки и ресурсы native-хостов обновлены. Аппаратный замер и его ограничения: [performance.md](performance.md).
